# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

ネオンの光る闘技場で弾を避けながら敵の群れを撃ち抜く、手触りを磨いた2〜5分遊べるWindows向けアーケードシューティングゲーム。（元のメモ：本気で作った、Windows の exe で遊べるゲーム（ジャンルはおまかせ））

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 使う人：Windows の PC で、休憩の合間に 2〜5 分だけ遊びたい人。アーケードのシューティングや、Steam・itch.io のインディーゲームが好きな人
  - 使う場面：exe をダブルクリックしてすぐ遊ぶ。キーボード（WASD＋矢印／マウス）かゲームパッドで、死んだら Enter か R ですぐにもう一度
  - 何度も遊ぶ理由：最高得点と到達ウェーブの更新、倍率を落とさずに稼ぐ遊び方、録画して人に見せたくなるオーバードライブと大物戦
- 技術：TypeScript・Vite（Canvas／WebGL）、テストはVitest。Electron で Windows の exe にして GitHub Releases で配る

## 画面

### タイトル

- 選択肢は「はじめる」（Enter／Space／パッドの A）と「せってい」の2つ。↑↓ で選び、Enter で決める。初めは「はじめる」

### 一時停止

- 選択肢は「つづける」「せってい」「やりなおす」「タイトルへ」。「せってい」を開いている間もゲームは進まない

### せってい

- タイトルの「せってい」、一時停止の「せってい」から開く。URL の `?scene=settings` でも直接開ける
- 項目は「効果音」「伴奏」「キーのわりあて」の3つ。「効果音」「伴奏」は 0〜10 の段階（0 は無音）。↑↓ で項目を選び、←→（A・D／パッドの十字キー・左スティック）で 1 段階ずつ変える。端で止まる。「キーのわりあて」は Enter で「キーのわりあて」画面を開く
- 変えたらその場で音に反映する。効果音を変えた時は短い確認音を鳴らす
- 戻るのは Esc／Backspace／パッドの B。戻ると、開いた場面（タイトル、または一時停止の「せってい」の選択）に戻る
- 既定値は両方 10。段階 n の音量は、10 の時の音量（効果音 0.9・伴奏 0.42）の n/10 倍
- 音量は localStorage（`neon-drift-arena.settings`）に保存し、次の起動でも保つ。保存が壊れていたり、一部の値が不正なら、その項目は既定値で起動する
- M キーのミュートは設定と別に働く（ミュート中も設定した音量は変わらない）

### キーのわりあて

- 「せってい」の「キーのわりあて」から開く。URL の `?scene=keys` でも直接開ける。戻る（Esc／Backspace／パッドの B）と「せってい」に戻る
- 変えられる操作は10個：移動（上・下・左・右）、射撃の向き（上・下・左・右）、ドリフト、オーバードライブ。最後に「もとにもどす」がある。↑↓ で選び、Enter で決める
- 操作を決めると「押すキーを待つ」表示になる。押したキーをその操作に割り当てる。Esc（またはパッドの B）でやめる。マウス左（射撃）とゲームパッドは変えられない
- 押したキーが他の操作に使われていれば、その操作と今のキーを入れ替える（同じキーが2つの操作に付くことはない）。入れ替え先で使えないキーになる場合は受け付けない
- 割り当てられないキー（予約）：Enter・NumpadEnter・Esc・Backspace（メニュー）、M（ミュート）、R（もう一度）、P（一時停止）、F11（全画面）、Tab。受け付けず「そのキーは使えません」と出し、待ちを続ける。↑↓ は射撃の上・下にだけ割り当てられる（メニューの ↑↓ は割り当てと別に働く）
- 既定は今のキー：移動 W／A／S／D、射撃 ↑／←／↓／→、ドリフト Space、オーバードライブ E。割り当てられるのは各操作に1キー
- 遊んでいるときは変えたキーで動く。タイトルの操作の案内と、HUD の「○ で発動」も割り当てに合わせて変わる。メニューの上下の W／S、←→ の A／D は割り当てと切り離して今のまま
- 「もとにもどす」で全部を既定に戻す
- localStorage（`neon-drift-arena.keymap`）に保存し、次の起動でも保つ。保存が壊れていれば全部既定値、使えないキーの項目だけは既定値、重複していれば全部既定値で起動する
