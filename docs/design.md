# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 考え

**この画面は「真夜中の闘技場で、ネオン管が自分の動きに合わせて脈打っている」ように見える。**

- 背景はほぼ黒。光るのは「意味のある物」だけ（自機・敵・弾・欠片・文字）。色の数を絞るほど、派手でも読める
- 光る物は全部「色の線＋白い細い芯」の2層で描き、画面全体に「にじみ（ブルーム）」をかける
- 色は意味で固定する：自分＝シアン、危険＝ピンク、ご褒美＝金。敵は種類ごとに1色
- 当たった・壊した・拾ったの全部に、揺れ・光・音のどれかで必ず返事をする

## 文字

- **英字・数字は「線の字」**（`src/lib/glyphs.ts` の升目 4×6 の折れ線。`src/game/neon-text.ts` で描く）。フォントは読み込まない。書ける文字は A–Z・0–9・`× . , : - + / !`・空白
  - 線の太さは字の高さの 0.075〜0.12。芯（白 85%）は線の 0.38
  - 字間は字幅の 0.3〜0.6（ロゴと見出しは 0.5〜0.6、「ARENA」は 1.7）
  - 見出し（ロゴ・WAVE・GAME OVER）は右に傾ける（skew 0.12〜0.14）
- **日本語**は `"Yu Gothic UI", "Yu Gothic", "Meiryo", "Noto Sans JP", "Noto Sans CJK JP", "Hiragino Sans", sans-serif`。太さは 500（本文）と 700（見出し・選択中）だけ
- 大きさは 1920×1080 を基準に `u = min(高さ/1080, 幅/1920)` を掛ける。日本語は **14px 未満にしない**（`Math.max(14, n*u)`）

## 画面の割り

- 闘技場は論理座標 **1600×900**。画面に `min(W/1740, H/1050)` 倍で収め、中央に置く（下へ 8u ずらす）。自機の方へ 5% だけ寄る
- 闘技場の外（上と下の帯）に HUD を1列ずつ置く。中には置かない
  - 上の帯：左端に得点 → 倍率 → 次の倍率までのバー（110u×5u）と「HI」。右端に「WAVE N」、その左に経過時間
  - 下の帯：左端に残機（自機の形、34u おき）、右端にオーバードライブのバー（260u×8u）と「OVERDRIVE」の文字。溜まったら「E で発動」（パッドは「RB で発動」）
  - 大物がいる間：上の帯の中央に「ガーディアン」と体力のバー（560u×8u）
- タイトル：ロゴは高さの 34% の所。「はじめる」は 64%。操作の案内は下から 92u、補足は下から 36u
- 結果：GAME OVER（13%）→ 得点（33%）→ 4つの数字（56%、1つ 230u の幅、間に細い縦線）→ 選択肢（76%）

## 部品の形

- **枠**：闘技場の四角＋四隅のシアンの鉤（長さ 70）。拍に合わせて明るさと太さが脈打つ。被弾中は赤
- **格子**：50 おきの線。爆発・ドリフト・出現で押され、ばねで戻る。歪んだ所だけ gridHot で明るく
- **自機**：矢じり形（シアン、線 3＋芯）。動くと後ろに炎。ドリフト中は残像。足元の弧＝ドリフトの溜まり
- **敵**：ドリフター＝ひし形＋中の小さなひし形／ダーター＝細い矢じり（突進の前に点線の予告）／スプリッター＝四角＋中の小さな四角3つ／タレット＝六角形＋スポーク（撃つ前に縮むピンクの輪）／ガーディアン＝回る8つの弧＋八角形＋金のひし形＋赤い芯
- **出現の予告**：敵の色の、縮む輪と十字（0.9 秒。大物は 1.6 秒）
- **弾**：自分＝速さの向きに伸びた線（シアン 5＋芯 2）。敵＝色の玉（半径 7）＋白い芯
- **欠片**：金の小さなひし形が回る。消える前の 1.5 秒は点滅
- **選択肢**：選択中は player の帯（幅 340〜360u、高さ 52u）＋左に 4u の縦線、文字は player の 700

## 動き（手触り）

| 出来事 | 返事 |
| --- | --- |
| 撃つ | 0.082 秒おき。反動で少し下がる、銃口に火花、高い短い音（ピッチを ±6% 揺らす） |
| 敵に当てる | 敵が 0.07 秒白く光る・押し戻される・火花2つ・短い音 |
| 敵を壊す | 火花と破片と光の輪、格子が押される、揺れ（小 0.1〜大 0.9）、ヒットストップ（0.022〜0.22 秒）、得点が飛ぶ |
| 欠片を拾う | 音階が上がっていく音。8個で倍率 +1（金の輪と `×N`、和音）。倍率 5・10 で射撃が広がる |
| ドリフト（Space） | 0.17 秒の突進、0.2 秒無敵、触れた敵の弾は欠片に変わる。0.9 秒で溜まり直す |
| 被弾 | 最大の揺れ、0.16 秒止まる、0.75 秒スロー、赤い光と縁、周りの弾が消え敵が押し返される、伴奏がこもる |
| オーバードライブ（E） | シアンの衝撃波が画面を横切り、雑魚は全部壊れ、弾は得点に変わる。大物は体力 30% |
| 波の始まり | 「WAVE N」が大きく出て縮む＋和音。新しい敵の名前と説明を日本語で出す |

- 画面の揺れは「トラウマ」式（強さの2乗で揺れ、実時間で減る）。スローの間も同じ速さで収まる
- 伴奏は 124 BPM の Aマイナー（Am–F–C–G）。波が進むと太鼓→手拍子→アルペジオ→裏打ちの順に厚くなる
- `prefers-reduced-motion` のとき：画面の揺れ・格子の波・ロゴの明滅を止め、光（フラッシュ）は 4 割に弱める

## 文言（画面に出る日本語）

- タイトル：「光る闘技場で、弾をすり抜け、群れを撃ち抜け。」「Enter か Space で はじめる」（パッド：「A ボタンで はじめる」）
- 操作：移動／射撃／ドリフト／オーバードライブ。補足「ドリフト中は無敵。触れた敵の弾は金の欠片に変わる。欠片を集めると倍率が上がる。」
- 一時停止：「一時停止」「つづける」「やりなおす」「タイトルへ」「↑↓ で選んで Enter」
- 結果：「スコア」「新記録！」「最高 N」「到達ウェーブ」「生存時間」「撃破数」「最高倍率」「もう一度」「タイトルへ」「R ですぐにもう一度」
- 波：「群れを撃ち抜け」「新しい敵：〇〇 — 説明」「ガーディアン接近 — 弾の渦に気をつけて」「射撃が広がった」「残機が1つ増えた」
- 英字の見出し（線の字）：NEON DRIFT / ARENA / WAVE N / OVERDRIVE / POWER N / EXTEND / GUARDIAN DOWN / GAME OVER / BEST / HI

## 避けること

- 純黒 `#000` の背景、白い面の背景
- 色の意味を崩す（敵にシアン、自分にピンクを使うなど）
- 線の字に無い文字を線の字で書く（日本語は必ず日本語の書体で）
- HUD を闘技場の中に置く。読ませる日本語を 14px 未満にする
- 外の画像・音・フォントのファイルを読み込む（全部コードで描き、Web Audio で鳴らす）
- 実在のゲームのキャラクター・名前・ロゴ
