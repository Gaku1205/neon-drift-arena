# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

ネオンの光る闘技場で弾を避けながら敵の群れを撃ち抜く、手触りを磨いた2〜5分遊べるWindows向けアーケードシューティングゲーム。（元のメモ：本気で作った、Windows の exe で遊べるゲーム（ジャンルはおまかせ））

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 使う人：Windows の PC で、休憩の合間に 2〜5 分だけ遊びたい人。アーケードのシューティングや、Steam・itch.io のインディーゲームが好きな人
  - 使う場面：exe をダブルクリックしてすぐ遊ぶ。キーボード（WASD＋矢印／マウス）かゲームパッドで、死んだら Enter か R ですぐにもう一度
  - 何度も遊ぶ理由：最高得点と到達ウェーブの更新、倍率を落とさずに稼ぐ遊び方、録画して人に見せたくなるオーバードライブと大物戦
- 技術：TypeScript・Vite（Canvas／WebGL）、テストはVitest。Electron で Windows の exe にして GitHub Releases で配る
